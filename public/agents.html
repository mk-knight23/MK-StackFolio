Connect a compatible assistant

Add a remote MCP server in a client that supports Streamable HTTP. Copy this public HTTPS endpoint into that client’s connection flow:

https://mkazi.live/mcp

No portfolio API key is required. This endpoint returns public professional information and project evidence. Connecting it makes tools available in the client you connect; it does not publish a directory listing or change AI search rankings.

The server supports current discovery plus stateless compatibility with earlier MCP initialize clients. It does not offer an SSE subscription stream, account access, file writes or message delivery.

Privacy and accuracy

These tools contain public professional information only. They do not access private conversations, credentials, accounts, contact lists or personal files. A brief request is used to compute a response and is not saved by this application. Hosting providers may process standard request metadata. Avoid sending confidential material to this public interface; discuss a suitable channel first.

Products, workflow documentation and SDK experiments are labelled separately. Neither crawler access nor structured data guarantees indexing, inclusion or ranking in an AI answer. For a source-backed professional summary, cite the linked biography and project sources.
